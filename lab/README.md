# lab — стенд, на котором проверялся доклад

Лабораторный код, который запускался на установках Joomla 6.1.4 и 6.2.0-rc2. Это не готовые расширения, а стенд для проверки утверждений доклада; номера категорий, меток и полей и логин `admin` взяты со стенда.

## Плагины

| Каталог | Группа | Что делает |
| --- | --- | --- |
| `plg_system_wmlab/` | `system` | подключает ассеты (короткий и полный адрес) в событии *onBeforeCompileHead*; проба редиректа и текущего адреса в событии *onAfterRoute* |
| `plg_console_wmlab/` | `console` | команды `wmlab:hello` и `wmlab:article` |
| `plg_task_wmlab/` | `task` | тип задачи для планировщика, который пишет строку в `tmp/wmlab-task.txt` |

Провайдеры сервисов записаны по образцу плагинов ядра — `set()` с `lazy()`. Установка: каталог плагина упаковывают в архив и ставят командой `php cli/joomla.php extension:install --path=архив.zip`, затем включают плагин.

## Сценарии

Каталог `scripts/` — сценарии, которые кладут в `cli/` рядом с `joomla.php`; каждый начинается с пояснения, что он проверяет.
